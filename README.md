# Green City Navigator

Цифровая платформа для климат-устойчивого городского развития в Худжанде.

## Что это

Прототип системы мониторинга и прогнозирования:
- Качество воздуха (PM2.5, AQI)
- Остров тепла
- Водные ресурсы
- Климат

## Партнёры

- YGPE (Худжанд)
- Институт водных проблем АН РТ
- GIZ

## Технологии

- Python 3.10+
- PostgreSQL + PostGIS
- FastAPI
- Streamlit
- PyTorch / scikit-learn
- Docker
